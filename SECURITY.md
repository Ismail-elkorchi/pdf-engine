# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | development security fixes |
| `0.1.x` | security fixes |

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories:

`https://github.com/Ismail-elkorchi/pdf-engine/security/advisories/new`

Include a minimal reproduction, expected and observed behavior, impact, affected
runtime, and the commit or version tested. Do not file a public issue for a
suspected vulnerability.

PDF files are untrusted input. Reports involving malformed structures,
resource-exhaustion paths, unsafe actions, encryption, parser differentials, or
unexpected host access are in scope.

Please allow time to confirm impact and prepare a safe fix before public
disclosure.
